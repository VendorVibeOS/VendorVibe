Offline-first promise

Business records are stored in IndexedDB on this device. Core sales, inventory, customers, orders, expenses, reports, adjustments and the offline Coach continue without internet.

Online sync

When configured, VendorVibe can synchronize the local business record to your own Firebase project. GitHub stores the app code; Firebase stores vendor data.

Advanced AI Coach

The offline Coach always works. When online, you can connect a secure AI gateway that calls Gemini. Do not place a Gemini secret API key directly in this PWA.

PWA installation

After hosting this folder over HTTPS, users can install VendorVibe from a supported browser and use it like an app.
